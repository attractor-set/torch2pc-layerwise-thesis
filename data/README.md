# Каталог данных

[English version](README_EN.md)

Каталог `data/` предназначен для локальных наборов данных и исключён из Git.
Публичный выпуск диссертации `v1.0.0` не требует повторной загрузки данных и не
разрешает повторное научное выполнение завершённых протоколов.

Исторический этап подготовки выполнялся через `make prepare` и фиксировал:

- список файлов;
- размер каждого файла;
- SHA-256;
- доступные метаданные версии набора данных;
- параметры преобразования.

Во время зарегистрированных научных выполнений данные использовались как заранее
подготовленные локальные assets: загрузка или изменение набора данных внутри
самого выполнения не допускались.

Новый научный эксперимент после `v1.0.0` должен получить собственный протокол,
новую авторизацию и отдельную фиксацию data assets; он не считается продолжением
или повтором закрытого выполнения только потому, что использует этот каталог.
