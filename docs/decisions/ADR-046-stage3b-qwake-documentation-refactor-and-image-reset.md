# ADR-046: полный рефакторинг документации `QWake` и сброс идентичности образа

[English version](ADR-046-stage3b-qwake-documentation-refactor-and-image-reset_EN.md)

- **Статус:** принято как `QW-4B-DOC-R1`;
- **Дата:** 2026-07-24;
- **[Выполнение](../glossary.md#term-execution):** не производилось;
- **[Доказательные материалы](../glossary.md#term-evidence):** отсутствуют.

## Контекст

[Кандидат](../glossary.md#term-candidate) `QW-4B-F-v1` успешно связал старую фиксацию версии исходного кода,
контейнерный образ, предварительную проверку, квитанцию статических проверок и
одноразовое разрешение. До выполнения обнаружилось, что активный текстовый план
смешивает ответ, вычислительный способ и стоимость, а также сохраняет старую
последовательность `QW-5 → QW-6 → … → QW-10` рядом с новым расширением.

Точечное исправление терминов могло бы пройти документационные проверки, но не
устранило бы концептуальное расхождение.

## Решение

1. Вывести старые предварительную проверку, квитанцию и разрешение из обращения
   до выполнения и сохранить их только во внешнем журнале аудита.
2. Не переписывать исторические `ADR-042`–`ADR-045` и ранее запечатанные
   доказательные материалы.
3. Полностью переписать активные разделы плана, дорожной карты, границы будущей
   политики, статуса и рабочего журнала.
4. Зафиксировать разделение `R`, `M`, `Γ` и `C`, два отношения эквивалентности и
   семейство `LOCAL_COMPUTE`.
5. Заменить активную последовательность на:

```text
QW-4B-DOC-R1
→ new immutable baseline image
→ QW-4B-F-v2
→ QW-4B-E-v2
→ sealed baseline report
→ QW-LC0 → QW-LC1 → QW-LC2 → QW-LC3
→ QW-LC4-I → QW-LC4-F → QW-LC4-E
→ QW-5 → C1 → C2 → C3 → R
```

6. После слияния документационного рефакторинга собрать новый неизменяемый образ
   и заново выпустить предварительную проверку, квитанцию и одноразовое
   разрешение.

## Граница утверждений

Документационный рефакторинг не реализует [аналитическое завершение](../glossary.md#term-analytic-completion), не выполняет
`FixedPred`, не создаёт инженерный отчёт и не открывает научную кампанию.
Первый аналитический кандидат остаётся ограниченной будущей гипотезой.

```text
old_authorization_reuse_permitted=false
new_image_required=true
new_runtime_preflight_captured=false
new_runtime_authorization_issued=false
runtime_execution_performed=false
engineering_evidence_present=false
local_compute_implementation_open=false
scientific_image_freeze_permitted=false
```

## Последствия

Новый образ обязан указывать фиксацию версии после слияния `QW-4B-DOC-R1`. Любой новый
пакет `QW-4B-F-v2` связывает только эту фиксацию версии и новый хеш образа. Старые
байты сохраняются как аудит, но не являются действующим разрешением.
