# ADR-048: доказательные материалы `QW-4B-E-v2` и восстановительное решение

[English version](ADR-048-stage3b-qwake-fp-runtime-validation-evidence-v2_EN.md)

- Статус: принято
- Дата: 25 июля 2026 года

## Контекст

Одноразовая [попытка](../glossary.md#term-attempt) `QW-4B-E-v2` была
выполнена из изолированного снимка исходного кода для коммита
`e413bb1e13cee42f702512e499f994e90df21e45` и Torch2PC
`b20d9142e4bdbf57b3ec8bf9f9c4472372ec8db4` в ранее зафиксированном
неизменяемом образе. Исполнитель завершил шесть ячеек
`CPU/ROCm × P0/P1/P2`, создал шестифайловый выход и запечатал инженерный
отчёт.

После успешного вычисления обёртка неверно сохранила статус аудита только
для чтения:
значение `PIPESTATUS` было прочитано после другой команды. Первый
восстановительный аудит затем ошибочно потребовал побайтовое равенство двух
эквивалентных сериализаций `JSON` разрешения, а второй ожидал несуществующее
поле `passed` вместо проверки `enabled=false` и нулевого вектора эффектов.
Повтор вычисления запрещён, поскольку разрешение уже использовано.

## Решение

1. Сохранить без изменения исходный выход, исходную ошибочную квитанцию
   завершения и оба неудачных восстановительных аудита.
2. Признать результат инженерными
   [доказательными материалами](../glossary.md#term-evidence) только после
   независимого восстановления v3, которое проверяет эквивалентность `JSON`
   и загруженных моделей, точные `P0/P1/P2`, CPU/ROCm, вложенность наблюдений,
   изоляцию эталонной проверки и
   нулевые эффекты отключённых возможностей.
3. Зафиксировать три раздельных слоя: точный вычислительный выход, полный
   пакет происхождения и восстановительного решения, а также внешнюю печать.
4. Считать разрешение окончательно использованным; повторная попытка не
   разрешена.
5. Не считать этот отчёт научным результатом и не открывать публикацию,
   тестовую выборку или `QW-LC0` в текущем срезе.

## Проверяемая граница

```text
qwake_qw4b_e_v2_runner_status=0
qwake_qw4b_e_v2_authorization_consumed=true
qwake_qw4b_e_v2_retry_permitted=false
qwake_qw4b_e_v2_runtime_rerun_performed=false
qwake_qw4b_e_v2_authorized_cell_count=6
qwake_qw4b_e_v2_cpu_lane_passed=true
qwake_qw4b_e_v2_rocm_lane_passed=true
qwake_qw4b_e_v2_engineering_evidence_present=true
qwake_qw4b_e_v2_image_freeze_eligible=true
qwake_qw4b_e_v2_scientific_evidence=false
qwake_qw4b_e_v2_publication_permitted=false
qwake_qw_lc0_open=false
```

## Последствия

Слияние этого среза завершает фиксацию базового инженерного отчёта в
репозитории.
Следующим самостоятельным срезом может быть только `QW-LC0`, начиная с
семантики и границ области, без ретроспективного изменения `QW-4B-E-v2`.
