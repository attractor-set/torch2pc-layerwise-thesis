# ADR-071: разрешение одноразового инженерного вызова `QW-LC4-E`

- Статус: принято
- Дата: 2026-07-28
- Срез: `QW-LC4-E-one-shot-engineering-invocation-authorization`

## Контекст

PR №131 слит в `main` коммитом `375db196b615f7024cd5f715de9c9be7b526a9f7` и независимо проверен.
Неизменяемый образ, пакет `execution-freeze-v1`, допуск одной попытки,
матрица из 168 ячеек и одноразовая точка входа уже существуют. Материализация
этих возможностей не равна разрешению конкретного вызова.

## Решение

1. Создать четырёхфайловый пакет `experiments/frozen/stage3b-qwake-lc4-e-one-shot-engineering-invocation-authorization-v1`.
2. Запись `authorization.json` разрешает ровно один будущий инженерный вызов,
   будущий захват файла владения и будущее [выполнение](../glossary.md#term-execution)
   синтетической матрицы.
3. Запись связывает коммит слияния, Torch2PC, неизменяемый образ, фиксацию
   выполнения, допуск, исходную матричную авторизацию, вычислительный модуль, обёртку и
   точку входа по точным SHA-256.
4. Разрешение внутри записи не открывает веточный эффект:
   `branch_runtime_execution_permitted=false`.
5. Текущий срез не создаёт файл владения, каталог результата или подготовительный каталог,
   не потребляет авторизацию и не вызывает модель.
6. Следующий отдельный срез должен реализовать хостовую обёртку вызова, которая
   сначала проверит этот пакет и только затем сможет вызвать точный
   неизменяемый образ.

## Следствия

- вызов разрешён как будущая способность, но ещё не выполнен;
- после захвата файла владения повтор остаётся запрещённым;
- научное выполнение, тестовая выборка и публикация остаются закрытыми.
