# ADR-084: реализация постоянной доказательной цепочки v2

- Статус: принято
- Дата: 2026-07-30
- Область: `QW-LC4-E`
- Основание: слияние PR №144 `3d092440b0314f02072c9773cc91018bf2860744`

## Контекст

ADR-083 определил полную доказательную цепочку, перспективный постоянный файл
владения v2 и обязательную устойчивую квитанцию терминального исхода хоста, но
намеренно не реализовал запись. Без отдельной реализации будущий
[запуск](../glossary.md#term-run) мог бы снова оставить авторизацию и
отрицательный исход только в памяти процесса.

## Решение

Реализовать два узких интерфейса записи:

1. эксклюзивную атомарную запись постоянного файла владения выполнением v2;
2. эксклюзивную атомарную запись устойчивой квитанции исхода хоста после
   проверки точных байтов уже записанного файла владения.

Оба интерфейса используют временный файл в целевом каталоге, режим `0600`,
полный `fsync` файла, атомарное продвижение посредством жёсткой ссылки без
перезаписи, `fsync` каталога и обязательную очистку временного файла. Цепочка
родительских каталогов должна уже существовать и не может содержать
символьные ссылки.

Интерфейс файла владения закрывается при наличии корня результатов, старого
файла владения, файла владения v2 или квитанции исхода. Интерфейс квитанции
закрывается при отсутствии либо несовпадении точных канонических байтов файла
владения. Любая коллизия запрещает перезапись.

## Граница

Реализация не подключается к исполнителю хоста и не вызывается текущей
операцией рабочей среды. Этот срез не инспектирует образ, не материализует
команду, не создаёт файл владения в реальном пути результатов, не потребляет
авторизацию, не создаёт дочерний процесс и не вызывает Docker. Все позитивные
тесты записи выполняются только в изолированных временных репозиториях.

## Следствия

- `PERSISTENT_LEASE_V2_IMPLEMENTATION_PRESENT=true`;
- `DURABLE_OUTCOME_WRITER_IMPLEMENTED=true`;
- `LEASE_BOUND_HOST_INVOKER_ENFORCED=false`;
- `FINAL_EXECUTION_ACKNOWLEDGED=false`;
- `ONE_SHOT_ENGINEERING_INVOCATION_PERMITTED=false`;
- фактические артефакты рабочей среды отсутствуют.
