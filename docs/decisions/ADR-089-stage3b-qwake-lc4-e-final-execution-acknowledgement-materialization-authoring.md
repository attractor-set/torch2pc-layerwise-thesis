# ADR-089: подготовка материализации финального подтверждения `QW-LC4-E`

- **Статус:** принято
- **Дата:** 2026-07-30
- **Область:** `QW-LC4-E`, финальное операторское подтверждение

## Контекст

PR №149 с реализацией атомарного механизма записи подтверждения слит как
`31206012ef7cbd2b7b21a2017374c11123abd42c` и независимо проверен. Механизм
записи существует, но производственная точка вызова и сам файл подтверждения
отсутствуют. До любого изменения производственного состояния требуется
отдельно зафиксировать, какие операторские данные, временная последовательность
и доказательная привязка образуют единственную допустимую запись подтверждения.

## Решение

Ввести статический, закрытый при ошибке контракт подготовки материализации:

1. Источником признаётся только реализация из PR №149 с точными
   идентичностями пакета, исходного кода, тестов и документации.
2. Будущая запись обязана содержать точную фразу
   `ACKNOWLEDGE_QWAKE_LC4_FINAL_ONE_SHOT_EXECUTION`, отдельные идентичности
   оператора и выпускающего, а также идентичность материализующего субъекта.
3. Материализующий субъект должен совпадать с выпускающим; это связывает
   производственное изменение с явно названной ответственностью.
4. Время операторского подтверждения должно быть строго после слияния PR №149;
   время выпуска не может предшествовать подтверждению, а время материализации
   не может предшествовать выпуску.
5. Должны быть связаны точный путь, канонические байты конверта, SHA-256,
   символ механизма записи и режим `0600`.
6. Требуются отсутствие целевого файла, существующий несимволический родитель,
   атомарная запись без перезаписи, `fsync` файла и каталога, очистка временного
   файла и повторная проверка точных сохранённых байтов.
7. Подготовка контракта не вызывает механизм записи. Фактическая
   материализация, файл владения, проверка образа, команда, Docker и
   [локальное вычисление](../glossary.md#term-local-compute) остаются отдельными
   действиями.
8. Одна материализация допускается не более одного раза; повтор запрещён.

## Следствия

После этого решения схема и происхождение будущего изменения состояния доступны
для независимой проверки, но производственное подтверждение всё ещё
отсутствует. Наличие контракта не разрешает вызов, не потребляет авторизацию и
не открывает локальное вычисление.
