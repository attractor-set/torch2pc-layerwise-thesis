# ADR-098: авторизация выполнения производственной точки вызова

- **Статус:** принято
- **Дата:** 2026-08-02
- **Контекст:** `QW-LC4-E`
- **Предшествует:** ADR-097

## Контекст

ADR-097 зафиксировал требования к будущему однократному запуску уже реализованной производственной точки вызова. После независимой проверки PR №164 требуется отдельный машиночитаемый срез, который связывает конкретного оператора, канонический объект операции и точную идентичность точки вызова, не выполняя действие.

## Решение

Создать один замороженный пакет `execution-authorization-v1`, содержащий:

1. `execution-authoring-merge-validation.json` с точной квитанцией проверки PR №164 после слияния;
2. `operation.json` — канонический предварительно сформированный объект операции;
3. `authorization.json` — однократное разрешение, привязанное к SHA-256 `operation.json`;
4. `source-SHA256SUMS` и `SHA256SUMS`.

Разрешение фиксирует оператора `dzmitry-prychyna`, отдельную фразу авторизации, точный путь и SHA-256 производственной точки вызова, шаблон аргументов, `invocation_count=1`, отсутствие оболочки и запрет повторной [попытки](../glossary.md#term-attempt).

## Семантика вступления в силу

Наличие `authorization.json` означает, что разрешение выпущено, но ещё не вступило в силу. Оно может стать основанием для выполнения только после:

- слияния этого среза;
- независимой проверки точного коммита после слияния;
- повторной проверки SHA-256 точки вызова и `operation.json`;
- подтверждения чистого рабочего дерева и отсутствия подтверждения, файлов владения, устойчивого исхода, каталога результата и временных файлов.

До проверки после слияния:

```text
EXECUTION_AUTHORIZATION_ISSUED=true
EXECUTION_AUTHORIZATION_POST_MERGE_VERIFIED=false
MATERIALIZATION_INVOCATION_OPERATION_CALLSITE_EXECUTION_AUTHORIZED=false
AUTHORIZATION_CONSUMED=false
PRODUCTION_CALLSITE_EXECUTED=false
```

## Однократность

Разрешение допускает только одну [попытку](../glossary.md#term-attempt). Потребление должно быть атомарно связано с началом [попытки](../glossary.md#term-attempt). После потребления автоматическая, слепая или ручная повторная [попытка](../glossary.md#term-attempt) на основании той же записи запрещена, включая отказ после неопределённого результата.

## Граница эффектов

Этот срез не выполняет производственную точку вызова, не вызывает библиотечную операцию, адаптер, материализатор или модуль записи, не создаёт итоговое подтверждение и не открывает [локальное вычисление](../glossary.md#term-local-compute).

## Последствия

После слияния и независимой проверки разрешения может быть открыт отдельный срез фактического однократного выполнения. Само слияние не является выполнением и не потребляет разрешение.
