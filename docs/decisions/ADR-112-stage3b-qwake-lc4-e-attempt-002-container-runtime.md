# ADR-112: изолированная контейнерная среда выполнения попытки 002

- **Статус:** принят в составе единственного корректирующего PR №179
- **Дата:** 2026-08-04
- **Связанное решение:** [ADR-111](ADR-111-stage3b-qwake-lc4-e-claim-execute-order-correction.md)

## Контекст

Терминальная [попытка](../glossary.md#term-attempt) 001 завершилась с ненулевым кодом возврата после создания владения v1. Повтор этой попытки запрещён. ADR-111 устранил дефект порядка проверки и фиксации, однако его первоначальная исправленная точка входа сохраняла ссылки на пути попытки 001 и историческую фиксацию образа. Такой объект нельзя использовать для новой попытки.

## Решение

Вводится отдельная версия контейнерной среды [выполнения](../glossary.md#term-execution) для попытки 002. Она определяет собственные пути выхода, владения v1, будущего владения v2 и устойчивого исхода хоста. Один объект допуска переносится через построение владения, атомарную фиксацию и [выполнение](../glossary.md#term-execution) заявленной обёртки.

Новая среда:

- не импортирует исторические модули допуска, потребления авторизации или устойчивой цепочки попытки 001;
- использует самостоятельные структуры фиксации образа, авторизации, допуска, владения и квитанций;
- повторно использует только неизменяемый вычислитель синтетической инженерной матрицы;
- применяет неперезаписывающее создание файла владения с режимом `0600`;
- применяет временное дерево и атомарное неперезаписывающее продвижение выхода;
- запрещает повтор после появления владения или выхода;
- не обращается к набору научных данных и не открывает публикацию.

## Граница текущего среза

Текущий срез только подготавливает код и проверяемый пакет. Он не материализует фиксацию исправленного образа, не создаёт авторизацию попытки 002, не создаёт владение, не строит образ и не вызывает среду выполнения.

```text
ATTEMPT_002_CONTAINER_RUNTIME_AUTHORED=true
CORRECTED_IMAGE_BUILT=false
ATTEMPT_002_EXECUTION_FREEZE_MATERIALIZED=false
ATTEMPT_002_AUTHORIZATION_ISSUED=false
ATTEMPT_002_LEASE_V1_PRESENT=false
ATTEMPT_002_LEASE_V2_PRESENT=false
ATTEMPT_002_DURABLE_OUTCOME_PRESENT=false
ATTEMPT_002_RUNTIME_STARTED=false
ATTEMPT_002_RUNTIME_PERFORMED=false
QW5_OPENED=false
```

## Последствия

Следующим допустимым действием после слияния этого коммита в PR №179 и независимой проверки является построение исправленного образа из точной головы PR. После построения должны быть отдельно материализованы идентичность образа, фиксация выполнения, одноразовая авторизация и проверка хостовой цепочки. До этого [запуск](../glossary.md#term-run) запрещён.
