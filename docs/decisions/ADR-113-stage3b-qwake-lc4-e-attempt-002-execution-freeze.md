# ADR-113: фиксация исправленного образа и среды выполнения попытки 002

- **Статус:** принят в составе единственного корректирующего PR №179
- **Дата:** 2026-08-04
- **Связанные решения:** [ADR-111](ADR-111-stage3b-qwake-lc4-e-claim-execute-order-correction.md), [ADR-112](ADR-112-stage3b-qwake-lc4-e-attempt-002-container-runtime.md)

## Контекст

После независимой проверки второго коммита PR №179 исправленный контейнерный образ был один раз построен из точного коммита `02afcc3e79b2d456cc3f1c075d4d792a0be608f7`. Контекст сборки получен через `git archive`, поэтому устойчивые объекты терминальной попытки 001 не входили в образ. Образ дважды проверен без создания контейнера и без [запуска](../glossary.md#term-run).

## Решение

Материализуется отдельная [фиксация](../glossary.md#term-freeze) выполнения попытки 002. Она связывает:

- точный исходный коммит и закреплённый коммит Torch2PC;
- идентичности контракта, обёртки, исполнительного модуля и контейнерной точки входа попытки 002;
- исправленный образ `sha256:f78fdbc699f3d00347d1dfdb78c03dd3df3957371f64eca9488de7cc06ce2b1d`;
- локальный идентификатор репозитория образа с тем же SHA-256;
- закреплённый базовый ROCm-образ;
- сохранённую внешнюю запись сборки `sha256:2aa105d8c13ef2408e674c08d7210c318a4baebf090b351ceb80ea1cf3de3902`;
- существующую научную авторизацию только как неизменяемый источник разрешённой инженерной матрицы;
- отдельные пути выхода, владений и устойчивого исхода попытки 002.

В репозитории сохраняется нормализованная идентичность образа и ссылка на внешний каталог записи сборки без абсолютного пути пользователя. Сам большой архив исходного кода, журнал сборки и полные ответы Docker остаются во внешнем неизменяемом каталоге.

## Граница текущего среза

Этот срез не создаёт одноразовую авторизацию попытки 002 и не подготавливает хостовую команду запуска. Образ существует локально, но контейнер не создавался.

## Последствия

Следующий допустимый срез должен сначала подготовить и независимо проверить исправленную хостовую цепочку вызова, связанную с новым идентификатором образа и путями попытки 002. Только после этого может быть отдельно подготовлена одноразовая авторизация. Слияние PR №179 и [выполнение](../glossary.md#term-execution) пока запрещены.
