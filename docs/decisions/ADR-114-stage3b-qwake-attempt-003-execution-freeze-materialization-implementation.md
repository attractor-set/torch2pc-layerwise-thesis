# ADR-114: реализация материализации фиксации выполнения попытки 003

## Статус

Принято как ограниченная реализация механизма будущей материализации.

## Контекст

ADR-113 закрепил точный объединённый исходный коммит
`541b34a57297d2c5a82851bd846b583d4904fba6`, набор из 13 исходных путей,
закреплённый базовый образ и требования к будущей фиксации
[выполнения](../glossary.md#term-execution). Сам образ ещё не построен, его
идентичность ещё не материализована, а фиксация выполнения отсутствует.

Существующий `Attempt003ExecutionFreeze` уже задаёт каноническую схему
`execution.json`. Поэтому этот срез не вводит второй контракт и не создаёт
сам пакет `stage3b-qwake-attempt-003-execution-freeze-v1`.

## Решение

Добавляется чистый файловый материализатор, который может быть вызван только
после отдельного разрешённого построения и неисполняющей проверки образа.
Он принимает ровно пять неизменяемых квитанций: `identity.env`,
`image-build.log`, `image-capture.json`, `image-inspection.json` и
`static-image-validation.json`.

Авторитетными для идентичности образа являются проверенные поля
`image-inspection.json`. Остальные квитанции сохраняются как входные
[свидетельства](../glossary.md#term-evidence) без вымышленной семантики.

До записи проверяются точный исходный коммит и ревизия `OCI`, закреплённый
базовый образ `OCI`, согласованность идентификаторов образа, точные `SHA-256`
четырёх компонентов [среды выполнения](../glossary.md#term-runtime), точный
коммит `Torch2PC`, научная авторизация и закрытая граница эффектов.

После этого формируется существующий `Attempt003ExecutionFreeze`, вычисляется
его каноническая контрольная сумма и в соседнем временном каталоге создаётся
девятифайловый пакет. Назначение должно отсутствовать; перезапись запрещена.
После локальной проверки временный каталог атомарно переименовывается в
канонический путь.

## Граница

Этот срез реализует только способность к будущей материализации. Он не строит
и не запускает контейнер, не материализует идентичность образа, не создаёт
фиксацию выполнения сейчас, не создаёт и не использует авторизацию попытки
003, не создаёт аренду или результат, не вызывает код среды выполнения или
модели и не обращается к [набору данных](../glossary.md#term-dataset).

Будущий материализатор разрешается вызывать только отдельной операцией после
получения реальных квитанций построения и проверки образа.
