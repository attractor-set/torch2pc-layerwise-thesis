# ADR-114: чистая хостовая цепочка вызова попытки 002

- **Статус:** принят в составе единственного корректирующего PR №179
- **Дата:** 2026-08-04
- **Связанные решения:** [ADR-111](ADR-111-stage3b-qwake-lc4-e-claim-execute-order-correction.md), [ADR-112](ADR-112-stage3b-qwake-lc4-e-attempt-002-container-runtime.md), [ADR-113](ADR-113-stage3b-qwake-lc4-e-attempt-002-execution-freeze.md)

## Контекст

ADR-113 закрепил исправленный образ, его локальную идентичность и отдельную [фиксацию](../glossary.md#term-freeze) выполнения попытки 002. До подготовки новой одноразовой авторизации требуется доказать, что хостовая сторона больше не использует идентичности, пути и командную цепочку терминальной попытки 001.

Исторические модули ADR-072—ADR-085 связаны с прежним образом и прежними путями эффектов. Их повторное использование для попытки 002 запрещено. Новая цепочка должна быть отдельной, проверяемой и неисполняющей.

## Решение

Добавляется чистая хостовая цепочка вызова попытки 002. Она:

- повторно проверяет пакет ADR-113 без требования переменных среды будущего контейнера;
- загружает точную нормализованную идентичность исправленного образа;
- принимает ответ `docker image inspect` только как входные данные и не вызывает Docker самостоятельно;
- требует точный идентификатор репозитория образа `torch2pc-layerwise-thesis@sha256:f78fdbc699f3d00347d1dfdb78c03dd3df3957371f64eca9488de7cc06ce2b1d`;
- задаёт только три монтирования: неизменяемые `experiments/frozen` и `external/Torch2PC`, а также доступный для записи каталог `results`;
- запрещает монтирование исходного дерева проекта и [набора данных](../glossary.md#term-dataset);
- фиксирует отключённую сеть, корневую файловую систему только для чтения, отсутствие дополнительных полномочий, удаление контейнера после завершения и точные GPU-устройства;
- проверяет канонические числовые идентификаторы пользователя и группы, значения CPU, памяти, общей памяти, временной файловой системы и числа потоков;
- строит точный вектор аргументов будущей команды как неизменяемые данные;
- не содержит процесса [запуска](../glossary.md#term-run), `subprocess`, автоматического повтора или устойчивой записи команды.

Будущая команда использует контейнерную точку входа попытки 002:

```text
/workspace/scripts/run_stage3b_qwake_lc4_attempt_002_authorized_runtime.py
```

Она передаёт точную отметку времени и фразу фиксации владения только после отдельной проверки будущей одноразовой авторизации. Наличие чистого конструктора команды не является разрешением на её применение.

## Проверяемые инварианты

1. Все идентичности образа совпадают с ADR-113.
2. Вектор команды использует только точный идентификатор репозитория образа.
3. Оболочечная интерпретация и наследование среды запрещены.
4. Исходный каталог проекта и [набор данных](../glossary.md#term-dataset) не монтируются.
5. Существующая авторизация или любой эффект попытки 002 закрывают поверхность подготовки.
6. Модуль не может создать процесс или контейнер.
7. Терминальные объекты попытки 001 не входят в пакет и не изменяются.

## Последствия

После независимой проверки этого коммита становится допустимой подготовка отдельной одноразовой авторизации попытки 002. Авторизация, её потребление, [запуск](../glossary.md#term-run) контейнера, создание владения, устойчивый исход и [выполнение](../glossary.md#term-execution) остаются отдельными будущими переходами. PR №179 пока не сливается.
