# Настройка GitHub

[English version](github-setup_EN.md)

Этот документ фиксирует **историческую процедуру первоначальной настройки**
репозитория. Для уже существующего публичного проекта `v1.0.0` он не является
текущим планом создания репозитория и не должен повторно выполняться как
процедура выпуска.

Историческая последовательность была следующей:

1. проверить данные автора и адрес репозитория в `CITATION.cff`,
   `pyproject.toml` и LaTeX;
2. выполнить `./scripts/bootstrap_github.sh`;
3. создать пустой удалённый репозиторий;
4. отправить ветку `main`;
5. включить задачи, обсуждения, проекты и защиту ветки GitHub;
6. сделать проверки `ci`, `docs` и `thesis-build` обязательными;
7. создать проект GitHub для управления исследовательскими задачами;
8. после первого публичного выпуска при необходимости связать репозиторий с
   архивным сервисом DOI.

Текущая процедура публикации диссертации определяется сценарием выпуска,
`scripts/build_release.sh`, `scripts/check_release_contract.py` и
`docs/validation.md`.
