# Ноутбуки

[English version](README_EN.md)

`analysis/` содержит analysis-only notebooks для чтения зарегистрированных
артефактов. Они не должны изменять экспериментальные конфигурации, выполнять
скрытую настройку гиперпараметров или определять новый scientific claim.

`legacy/full_pipeline_v11.ipynb` — историческая точка миграции ранней версии
проекта. Она сохраняется для regression/provenance целей и не является
оркестратором `v1.0.0`.

Каноническая исполняемая логика находится в `src/torch2pc_thesis/`; финальные
численные утверждения диссертации проходят отдельные thesis-facing проверки.
