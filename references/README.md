# Литература

[English version](README_EN.md)

Этот публичный каталог является канонической библиографической поверхностью
диссертации `v1.0.1`: он содержит библиографические данные и трассировку
источников, но не повторно распространяемые PDF статей.

Локальные PDF можно хранить в `references/pdfs/`, который исключён из Git.

Для выпуска `v1.0.1` библиография должна проходить полную сборку диссертации без
неопределённых цитат. Проверка машинной сборкой не заменяет содержательную
проверку первичных источников. Любое последующее изменение библиографии требует:

- сверить изменённую BibTeX-запись с первичным источником или записью издателя;
- убедиться, что источник содержательно используется в диссертации или явно
  относится к новому последующему материалу;
- сохранить корректную связь источника с утверждением, методом, набором данных
  или ограничением;
- удалить случайные дубли, не переписывая историческую библиографическую
  provenance без отдельного основания;
- повторно выполнить `make thesis-check` и финальную сборку документа.
