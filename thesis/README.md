# Финальная диссертация

[English version](README_EN.md)

`thesis/main.tex` — русская точка входа завершённой диссертации;
`thesis/main_EN.tex` — полное английское представление той же научной работы.
Репозиторный шаблон остаётся нейтральным относительно кафедральной титульной
формы. Научный текст, C01–C11 и доказательные привязки после T24 считаются
закрытыми; `v1.0.1` добавляет языковое представление, а не новый научный
результат.

## Сборка

```bash
make thesis-check
make thesis       # Russian / RU
make thesis-en    # English / EN
make thesis-all   # обе версии
```

`make thesis-check` включает отдельную проверку структурной и
научно-семантической RU/EN-конгруэнтности. Проверка дополнительно требует
совпадения структурных окружений и нормализованной последовательности меток, а
также контролирует соотношение объёма текста глав как барьер против пропуска
крупных фрагментов. Обе PDF используют одни и те же канонические тела RU/EN
аннотаций, меняя только их порядок. Английские таблицы и реестры генерируются
из тех же `thesis/data/*.json`, что и русская версия; перевод не имеет права
менять ID, статус или границу утверждения.

Зафиксированная T24 русская сборка содержит 99 страниц. Полная английская
сборка является отдельным документным артефактом и может иметь другое число
страниц из-за языковой длины и верстки; равенство числа страниц не является
критерием семантической эквивалентности.

## Машиночитаемый контракт диссертации

- `data/research_claims.json` — финальные C01–C11 и их эпистемические статусы;
- `data/thesis_traceability.json` — связь theory → methodology → experiment →
  result → discussion → conclusion;
- `data/qwake_c2_verified_summary.json` — независимо сверенная сводка C2 для
  диссертации;
- `../scripts/build_thesis_assets.py` — русские генерируемые assets;
- `../scripts/build_thesis_assets_en.py` — английские генерируемые assets из
  тех же научных контрактов;
- `../scripts/check_thesis_semantic_contract.py` — терминологическая дисциплина
  и семантика утверждений, включая действие QWake;
- `../scripts/check_thesis_traceability.py` — локальная привязка утверждений;
- `../scripts/check_thesis_language_congruence.py` — RU/EN структура,
  терминология, критические числа и статусы C08–C11.

Генерируемые `.tex`-артефакты не являются независимым источником истины: они
строятся из отслеживаемых данных и контрактов перед каждой сборкой.

## Релиз v1.0.1

Релиз публикует два явно различимых PDF:

```text
torch2pc-layerwise-thesis-1.0.1-ru.pdf
torch2pc-layerwise-thesis-1.0.1-en.pdf
```

Для каждого PDF публикуется отдельный SHA-256; общий manifest связывает оба
артефакта с одним source commit/tree.

## Финальная граница

C08 остаётся `supported`, C09 — `rejected`, C10/C11 — `not_tested`.
Ни перевод, ни сборка, ни операция выпуска не открывают повторное научное
выполнение и не меняют эти статусы.
