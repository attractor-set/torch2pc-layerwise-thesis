# Финальная диссертация

[English version](README_EN.md)

`thesis/main.tex` — исходная точка входа завершённой диссертации. Репозиторный
шаблон остаётся нейтральным относительно кафедральной титульной формы, но
научный текст, C01–C11 и доказательные привязки после T24 считаются закрытыми.

## Сборка

```bash
make thesis-check
make thesis
```

Проверка точного коммита T24 дала 99-страничную сборку без переполненных строк,
неопределённых ссылок/цитат и предупреждений о необходимости повторного прохода
перекрёстных ссылок. Сборщик выпуска `v1.0.0` повторяет документные проверки на
точном коммите выпуска и публикует PDF вместе с SHA-256 исходного архива и
манифестом commit/tree.

## Машиночитаемый контракт диссертации

- `data/research_claims.json` — финальные C01–C11 и их эпистемические статусы;
- `data/thesis_traceability.json` — связь theory → methodology → experiment →
  result → discussion → conclusion;
- `data/qwake_c2_verified_summary.json` — независимо сверенная сводка C2 для
  диссертации;
- `../scripts/build_thesis_assets.py` — сверка происхождения и числовых
  результатов;
- `../scripts/check_thesis_semantic_contract.py` — терминологическая дисциплина
  и семантика утверждений, включая семантику действия QWake;
- `../scripts/check_thesis_traceability.py` — локальная привязка утверждений.

Генерируемые `.tex`-артефакты не являются независимым источником истины: они
строятся из отслеживаемых данных и контрактов перед каждой сборкой.

## Финальная граница

C08 остаётся `supported`, C09 — `rejected`, C10/C11 — `not_tested`.
Никакая операция выпуска или документации не открывает повторное научное
выполнение и не меняет эти статусы.
